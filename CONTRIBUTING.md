# Contributing

Use Node 24. Edit src/pages and shared components, not generated dist files. Preserve all public HTML filenames, translations, design and third-party script ordering. Check all references before modifying a shared extracted block. Do not edit minified libraries casually.

Run npm run lint, npm test and npm run build. Include browser checks for visual/interaction changes. Never submit production forms in automated checks. Document missing assets and external setup instead of fabricating success. Keep PRs scoped and do not commit secrets, generated output or customer data.
